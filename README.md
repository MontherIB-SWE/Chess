# 🏭 Factory Control System

A **JavaFX application** for factory control, enabling **real-time database interaction, SQL query execution, and visual data representation**.

---

## 📖 Project Overview

The **Factory Control System** is a desktop application designed to streamline factory operations by providing a graphical interface for MySQL databases.

Users can:

* Connect to a factory database using credentials.

* Run **predefined SQL queries** for logs, values, and performance.

* View results in **tables and charts**.

* Run **single queries** or **multiple queries concurrently**.

* Follow an **in-app tutorial** to learn usage.

This makes monitoring and analyzing production logs easier and more efficient.

---

## 🚀 Tech Stack

* **Language:** Java (JDK 21 or higher)

* **Frontend/GUI:** JavaFX

* **Database:** MySQL (Connector/J 8.3.0 included)

* **Build Tool:** Apache Maven

---

## ▶️ How to Run

### Prerequisites

Before running the application, ensure you have the following installed:

* **Java JDK 21+**

* **Apache Maven**

* **MySQL server** with a schema and a table (e.g., `mine`) populated with data.

### Installation

1.  **Clone the repository**:

    ```bash
    git clone <repository-url>
    ```

2.  **Navigate to the project directory**:

    ```bash
    cd FactoryControlSystem
    ```

### Run the application

* **On Linux/macOS**:

    ```bash
    ./mvnw javafx:run
    ```

* **On Windows**:

    ```bash
    mvnw.cmd javafx:run
    ```
